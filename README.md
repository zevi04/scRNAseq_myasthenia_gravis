## Dataset

This project uses the publicly available **GSE227835** single-cell RNA sequencing dataset from the NCBI Gene Expression Omnibus (GEO).

**Dataset:** GSE227835 – *Single-cell RNA-seq data of human PBMC from Myasthenia Gravis patients*

### Download

The dataset can be downloaded from:

https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE227835

### Local Directory Structure

After downloading, organize the data as follows:

```text
DATA/
├── RAW/
│   └── GSE227835_RAW.tar
└── PROCESSED/
    └── Extracted *.txt.gz files
```

> **Note:** The dataset is not included in this repository because it is publicly available through GEO and is too large for version control.
